# Open Sonic JS integrado ao PIXEL

Esta pasta contém a versão web (`public/`) do projeto Open Sonic JS, copiada do repositório:
https://github.com/clarkeadg/opensonic-js

- A entrada integrada é `sonic.html`.
- O jogo roda em iframe isolado para não interferir nos outros minijogos.
- Foram adicionados controles de toque no HTML/CSS para esquerda, direita, pulo e Enter.
- Recursos e dados são carregados localmente a partir das pastas `data/` e `js/`.
- A licença MIT do código do projeto original foi preservada em `LICENSE-OpenSonicJS.txt`.

Observação: a licença do código não deve ser interpretada como garantia de que todos os personagens, sprites, sons ou músicas incluídos nos dados do projeto tenham licenças independentes para qualquer tipo de redistribuição. Verifique os créditos/licenças dos assets antes de publicar.
